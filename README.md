This Python Script is a desktop application built with Tkinter that scans NCMEC Cybertip files in PDF form. Capable of scanning numerous Cybertips at once. 
The script finds and extract filenames and MD5 hashes, then exports the results to an Excel spreadsheet and a plain text file.
The Excel file contains the source (Cybertip Number), File Name and MD5 Hash. 
The Plain Text file contains just the MD5 Hash values, and can be uploaded to triage tools for on scene previewing / searching.
